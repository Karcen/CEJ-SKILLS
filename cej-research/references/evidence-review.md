# 让结论与证据对应

## 按命题类型检查

| 命题 | 优先检查 | 不应自动升级为 |
|---|---|---|
| 概念或测量 | 定义是否互相混用，指标如何实现，覆盖哪些对象 | 已验证的因果机制 |
| 理论或模型 | 假设、传导链、闭合条件与适用状态 | 无条件经验规律 |
| 历史或思想史 | 材料来源、时间顺序、语境与竞争解释 | 当代政策效果估计 |
| 经验相关 | 样本、变量、比较组、遗漏因素与外推范围 | 因果效应 |
| 因果解释 | 冲击或处理来源、识别假设、反事实与制度支撑 | 适用于所有国家和群体的规律 |
| 政策判断 | 目标、约束、执行主体、融资、受益者与副作用 | 技术上可行即政治上可实施 |

表格是本包的综合检查框架。论文可以跨类型，但跨越每一层都需要额外论证。

## 用真实案例校准判断

Wang 等（S6）使用 2015 年欧洲工作条件调查和国家固定效应分析工作质量、数量与心理健康。固定效应不把横截面关联自动变成缩短工时的因果政策效果，也不能把研究误写成疫情实验。若要建议四天工作周，需另找直接对应干预和人群的证据。

Stemerding（S7）的三家企业、三个行业、一个国家示例能够展示租金度量如何工作，不能独自证明它已适用于所有行业与会计制度。复用时先检查成本处理、金融企业适用性及税收安排等边界。

Gash 等（S9）区分总体工资差距和社会经济组别的不同预测因素。平均结果不足以代表每个群体。阅读具体分解方法后再解释贡献项；不能把统计分解项直接称为干预该因素能消除的差距。

Durán（S11）使用倾向得分匹配。匹配改善可观测变量上的可比性，其因果解释仍取决于选择机制等假设；不能写成随机分配。制度史材料与匹配结果可以互相补充，但不是彼此的替代证明。

Raza 与 Khawaja（S12）将高频识别的货币政策冲击与部门分析结合。引用时区分“识别的冲击”和观察到的利率变化。需要复现时回到方法部分核对具体工具和估计式；本包未提炼完整复现方案。

## 比较争论：对齐对象，再判断冲突

从每篇文章中提取它实际反对的命题。Heise（S4）研究最低工资研究共同体如何回应预测与证据的矛盾；这不是一项新的最低工资就业效应估计。把它与效果估计比较时，说明二者的问题层次不同。

检查一个框架是否在每次证据不利时只修改辅助假设，并始终不给出可能推翻核心解释的观察。同样的标准也应适用于偏爱的替代理论。理论有韧性不等于不可证伪；单次预测偏差也不必然推翻全部框架。

Bee 与 Fèvre（S8）通过语境重读 Keynes 的淘金与战争比喻。重读可改变对机制与意图的理解，不能直接证明现代战争刺激政策有效。对思想史文章，避免把熟悉的一句名言当作作者立场的完整证据。

## 留下可复查的最小记录

记录 DOI、实际读过的章节、主张类型、证据、适用条件及拟用于何处。检索片段只能帮助定位；参考文献中的词语出现不等于正文支持某一结论。引用具体估计、公式或政策数值前复核原文，尤其是 PDF 页码与印刷页码不同的情况。

当两个来源结论不同，先比较定义、单位、时期、制度和识别对象。仅当这些相近时才将其表述为直接冲突。不要通过对观点计票构造期刊立场。
